# battlecity-web

Web reimplementation of the classic NES game Battle City. Fan project, not affiliated with Namco.

Open `index.html` through a local static server:

```bash
python3 -m http.server
```

## Sources

- [Battle City](https://en.wikipedia.org/wiki/Battle_City_(video_game)) (Namco, 1985) — the original Famicom/NES game.
- [vgrichina/battlecity](https://github.com/vgrichina/battlecity) — Famicom stage maps and a reference for the mechanics.
- [Ностальгия: роемся у «Танчиков» под капотом](https://habr.com/ru/articles/142126/) — enemy behavior: tank and shell speeds.
- [Battle City asset catalog](https://battle-city.berrry.app/catalog.html) — sprites, terrain, HUD and sounds.

The intact base is an original pigeon. Themed bonus stages after the 35 Famicom maps are original to this project.
